# Народный рейтинг

Одностраничный сайт-каталог с отзывами об организациях.
Пользователь может искать компании, фильтровать по категориям, сортировать список и оставлять новые отзывы.

## Что умеет сайт

- Показ карточек организаций с рейтингом, количеством отзывов и кратким описанием.
- Фильтрация по категориям.
- Поиск по названию организации.
- Сортировка по рейтингу и количеству отзывов.
- Пагинация списка.
- Просмотр всех отзывов в отдельном модальном окне.
- Добавление нового отзыва:
  - в существующую организацию;
  - или с созданием новой организации прямо из формы.
- Плавающие анимации, анимированные счётчики и toast-уведомления.

## Как запустить

1. Откройте файл `index.html` в браузере.
2. Готово: сборка, npm и сервер не требуются.

Альтернатива: можно запустить через Live Server в редакторе, если так удобнее.

## Как это работает (по шагам)

### 1) Инициализация

При загрузке страницы вызывается `init()`:

- создаются декоративные частицы (`createParticles()`);
- загружаются данные из `localStorage` (`loadFromStorage()`);
- выполняется первичный рендер (`render()`);
- обновляется статистика в hero-блоке (`updateHeroStats()`).

### 2) Откуда берутся данные

- Ключ хранилища: `nr_organizations`.
- Если в `localStorage` данных нет, используются стартовые данные из `DEFAULT_ORGANIZATIONS`.
- Для каждой организации пересчитываются:
  - `reviewsCount`;
  - `rating` (среднее по отзывам, округление до 1 знака).

### 3) Рендер главного списка

Главный рендер разбит на три части:

- `renderCategories()` — кнопки категорий.
- `renderCards()` — карточки организаций (с учётом фильтров, поиска и сортировки).
- `renderPagination()` — кнопки страниц.

На страницу выводится `ITEMS_PER_PAGE = 6` карточек.

### 4) Фильтры, поиск и сортировка

Функция `getFilteredOrgs()` применяет логику в таком порядке:

1. фильтр по категории (`activeCategory`);
2. поиск по названию (`searchQuery`);
3. сортировка (`sortMode`):
   - `default`;
   - `rating-desc`;
   - `rating-asc`;
   - `reviews-desc`.

Изменение фильтров/поиска/сортировки сбрасывает страницу на первую и перерисовывает список.

### 5) Добавление отзыва

Форма в модальном окне `#addReviewModal`:

- поле организации с автодополнением;
- если организации нет, можно выбрать «добавить новую», тогда показывается выбор категории;
- выбор рейтинга звёздами;
- ввод имени и текста.

При отправке формы:

- проходит валидация полей;
- создаётся новая организация (если выбран режим `new`) или берётся существующая;
- в массив `reviews` добавляется новый отзыв с текущей датой;
- пересчитываются рейтинг и количество отзывов;
- данные сохраняются в `localStorage`;
- обновляются карточки и счётчики;
- показывается toast-уведомление.

### 6) Просмотр отзывов

Кнопка «Читать» открывает `#reviewsModal`:

- сверху показывается сводка по организации;
- ниже — список отзывов в обратном порядке (сначала новые);
- для автора генерируются аватар-инициалы и цвет.

## Структура данных

Организация (упрощённо):

```js
{
  id: Number,
  name: String,
  category: String,
  previewText: String,
  reviews: [
    {
      id: Number,
      author: String,
      date: String, // dd.mm.yyyy
      rating: Number, // 1..5
      text: String
    }
  ],
  reviewsCount: Number,
  rating: Number
}
```

## Внешние зависимости

Подключаются через CDN прямо в `index.html`:

- Google Fonts (`Inter`)
- Font Awesome (`6.5.0`)

## Где менять поведение

- Стартовые организации: `DEFAULT_ORGANIZATIONS`.
- Категории, иконки и цвета: `CAT_META`.
- Количество карточек на странице: `ITEMS_PER_PAGE`.

## Важно знать

- Это полностью клиентское приложение, без backend/API.
- Все добавленные отзывы хранятся только в браузере пользователя (`localStorage`).
- В другом браузере/устройстве данные не появятся автоматически.
